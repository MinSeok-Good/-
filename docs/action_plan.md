# Operational action plan

현재 데이터만으로 AI가 정비 우선순위를 자동 확정하지 않습니다. 모델의 역할은 이상 후보를 선별하고 현장 의사결정을 지원하는 것입니다.

## Proposed workflow

`센서 → 이상탐지 → 표준 점검 템플릿 → 현장 담당자 판단 → 조치 → 결과 기록 → 향후 모델 고도화`

## 표준 점검 템플릿 후보

| 구분 | 예시 항목 | 입력 주체 |
|---|---|---|
| AI 정보 | 이상확률, 지속시간, 반복 여부 | 자동 |
| 설비 정보 | 중요도, 대체설비 여부 | 사전 등록/설비 담당 |
| 위험 정보 | 공정 영향도 | 설비 담당 |
| 생산 정보 | 생산중단 영향 | 생산·설비 담당 |
| 정비 정보 | 최근 고장/정비이력 | CMMS 또는 담당자 |
| 현장 판단 | 실제 증상, 점검 결과 | 엔지니어 |
| 조치 결과 | 관찰, 점검, 계획정비, 부품교체 등 | 엔지니어 |

가중치와 행동 threshold는 본 데이터셋만으로 정하지 않습니다. 실제 공장 정책과 정비 결과가 축적된 뒤 전문가 합의를 통해 설정해야 합니다.

향후에는 매뉴얼과 과거 정비이력을 검색하는 RAG를 연결하고, `센서 패턴 + 설비정보 + 현장 판단 + 실제 조치 결과`를 축적해 조치 추천 모델로 확장할 수 있습니다.
